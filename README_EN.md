## ✨ What is AIPC UP?

**AIPC UP** is not just another conversational chat window. It is a **local-first AI Agent desktop workspace** deeply integrated into the Windows operating system.

It allows AI Agents to live directly on your PC. Beyond understanding natural language and real-time voice dictation, it operates your computer just like a skilled human assistant within the boundaries of your authorization:

- 👥 **Multi-Agent Teamwork**: Group multiple specialized AI Agents (architecture, coding, UI design, testing) to collaborate concurrently in team chat, breaking down goals and tackling complex workflows.
- 🖥 **Full Desktop & Browser Automation**: Native mouse/keyboard simulation and window management for local desktop software; integrated browser automation engine (Browser Harness) utilizing Chrome DevTools Protocol (CDP) for accurate DOM perception, dynamic clicks, and cross-site form automation.
- 📺 **Native Remote Control & Screen Wall**: Real-time visual monitoring dashboard capturing primary display dynamics. Scan a QR code from your mobile phone to take control instantly, featuring a specialized **Virtual Touchpad Joystick** (trackpad, left-click drag, right-click menu) and **360° Infinite Scroll Wheel** without installing any third-party remote tools.
- 🗂 **Standalone Full-Disk File Management**: Explore disks and double-click to "drill into" folders just like Windows File Explorer. Instant full-disk search, drag-and-drop uploads, batch ZIP packaging, and zero-memory streaming downloads.
- 🎙 **Real-Time Voice & Mini Floating Window**: Press <kbd>Ctrl+M</kbd> for fluid speech-to-text with bilingual punctuation; press <kbd>Alt+Q</kbd> to summon the ultra-compact 48px floating window for zero-occlusion desktop workflows.
- ⏰ **24/7 Always-On & Scheduled Tasks**: Standard Cron scheduling to wake up your PC in the background, summarizing daily reports, monitoring data, and automating recurring jobs.
- 📱 **Secure Remote Access & Chat Channels**: Built-in encrypted tunneling. Access your desktop workspace via WebUI on mobile/tablet, or dispatch tasks directly through **WeChat, Enterprise WeChat, Feishu/Lark, DingTalk, and Telegram**.

All project files and runtime environments **remain strictly on your local machine by default**, safeguarding your privacy and data sovereignty.

## ⚡ 3-Step Quick Start & 3 Model Setups

> 💡 Step-by-step documentation: [Install & Launch](https://huiai.io/aipc-up/docs/en/getting-started/install/) · [Required Setup (3 Model Routes)](https://huiai.io/aipc-up/docs/en/getting-started/required-config/)

### Step 1: Download and Install AIPC UP
1. Visit the [GitHub Releases](https://github.com/learncodesmart/AIPC-UP/releases/latest) page and download `AIPC.UP.Setup.<version>.exe`.
2. Run the installer to launch AIPC UP in seconds.
3. On the first launch, create a **Local Account** (stored securely and encrypted on your device for mobile login verification).

### Step 2: Configure Models (Choose from 3 Routes)
Navigate to **Settings**, and pick the connection route that best suits your needs:

| Route | Best For | Details & Requirements |
| :--- | :--- | :--- |
| **Route A: HuiAI Official (Easiest, Recommended)** | Ready-to-use out-of-the-box experience | Paste your [HuiAI Access Token](https://huiai.io/token/) in "Settings → HuiAI Config" to automatically synchronize official channels and premium features. |
| **Route B: Custom API Key (Self-Managed)** | Direct provider APIs / Custom relays | Add your Base URL, API Key, and Model Name for DeepSeek, Kimi, SiliconFlow, OpenAI, etc. under "Settings → Models". |
| **Route C: Local Offline Ollama (100% Private)** | Running on local GPU hardware | Directly connect to your locally running Ollama instance with zero external network dependency. |

Click **Test Connection** to ensure connectivity.

### Step 3: Run Your First Local Task
1. Open or select a folder in the workspace panel (use a non-critical directory for testing).
2. Choose your preferred AI core or assistant (such as **Desktop Automation** or **Aion CLI**).
3. Send the following prompt (or press <kbd>Ctrl+M</kbd> to dictate):

```text
Inspect this folder in read-only mode and summarize what files it contains in three sentences. Do not modify any files.
```

4. When the permission dialog appears, verify the directory path and click **Allow**.
5. Once the AI returns the folder summary, your local AI workspace is verified and ready for work!

> 💡 **Tip for New Users**: After configuring your models, try pressing <kbd>Ctrl+M</kbd> for voice dictation and <kbd>Alt+Q</kbd> to summon the mini floating window. Once comfortable, explore Screen Wall remote control, automation agents, and multi-agent teams.

## 🛡 Local-First Architecture & Safety

AIPC UP can perform real system operations. It adheres strictly to **local-first principles and the principle of least privilege**:

* 🏠 **Local-First Data Ownership**: Your codebases, documents, and environment files stay strictly on your local PC.
* 🔐 **Granular Permission Control**: File edits, shell command execution, network requests, and mouse/keyboard controls require explicit user confirmation.
* 👁 **Full Execution Transparency**: Tool calls, file diffs, and execution logs are displayed clearly in real time.
* ⏯ **Instant Intervention**: Pause, stop, or rollback ongoing agent operations at any moment. Press <kbd>Shift</kbd> + <kbd>Esc</kbd> on desktop or tap exit on mobile to instantly terminate remote control sessions.

*Learn more: [Data and Privacy](https://huiai.io/aipc-up/docs/en/security/privacy/) · [Tokens and Credentials](https://huiai.io/aipc-up/docs/en/security/tokens/)*
