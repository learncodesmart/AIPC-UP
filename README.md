## ✨ AIPC UP 是什么

**AIPC UP** 不是简单的模型聊天窗口，而是深度融合在 Windows 操作系统中的**本地优先 AI Agent 智能工作台**。

它让 AI 真正“住在”你的电脑里，不仅能听懂你的自然语言和语音输入，更能像专业人类助理一样，在你授权的范围内直接操作电脑完成复杂工作：

- 👥 **多 Agent 组队协作**：让负责架构、写代码、做设计、写测试的多个 AI 智能体并行工作，在群聊中自主分工、交替质询，协作攻克复杂大任务。
- 🖥 **桌面与网页双重全能自动化**：原生模拟 Windows 键鼠操作与窗口定位，打通本地专业软件；内置浏览器自动化引擎（Browser Harness），支持 DOM 树精准感知与元素智能定位，自动完成跨网站信息采集与表单批量填写。
- 📺 **轻量原生远程控制与屏幕墙**：秒级捕获电脑桌面动态，为后台自动化、微信远程派活提供实时监工大屏；手机扫码秒级接管电脑，内置专为触控打造的**悬浮飞鼠手柄**（随身触控板、侧翼左键拖拽与右键菜单）与 **360° 无极滚轮转盘**，支持多显示器自由切换与按需休眠省流。
- 🗂 **独立全盘文件管理**：像 Windows 资源管理器一样双击“钻入”文件夹，支持全盘即时搜索、拖拽上传、ZIP 批量打包与零内存极速流式下载，彻底告别黑底命令终端。
- 🎙 **实时语音听写与悬浮置顶小窗**：按 <kbd>Ctrl+M</kbd> 动嘴流式打字，CJK 标点智能断句；按 <kbd>Alt+Q</kbd> 随时呼出 48px 极简置顶小窗，边查资料写方案边随叫随问，工作视野零遮挡。
- ⏰ **全天候 24/7 常驻与定时任务**：支持标准 Cron 定时工作流，自动在后台定时唤醒电脑执行周期性维护、日报汇总与数据抓取。
- 📱 **安全公网远程与多端外联**：内置安全内网穿透技术。通过 WebUI 在手机/平板流畅操作桌面工作台，并支持通过**微信、企业微信、飞书、钉钉、Telegram**直接下发任务指令。

所有文件与运行环境**默认 100% 保留在你的本地电脑**，保障个人与企业数据资产隐私安全。

## ⚡ 3 步极速上手与三种起步方式

> 💡 完整图文教程见帮助文档：[安装与启动](https://huiai.io/aipc-up/docs/getting-started/install/) · [模型配置 (三种起步方式)](https://huiai.io/aipc-up/docs/getting-started/required-config/)

### 步骤 1：下载并安装 AIPC UP
1. 前往 [Releases 发布页面](https://github.com/learncodesmart/AIPC-UP/releases/latest) 下载最新的 Windows 安装包 `AIPC.UP.Setup.<version>.exe`。
2. 双击运行安装程序，秒级启动进入主界面。
3. 初次启动按提示创建**本地工作台账号**（仅加密保存在本机，用于后续手机扫码或远程访问安全登录）。

### 步骤 2：完成模型与算力配置（三种起步方式任选）
进入 **设置 (Settings)**，根据你的实际环境选择最适合的模型起步方式：

| 起步路线 | 适用场景 | 需要提供的内容与说明 |
| :--- | :--- | :--- |
| **路线 A：慧AI 官方接入（最省心，推荐）** | 已有慧AI 账号，一键开箱即用 | 在「设置 → 慧AI配置」粘贴 [慧AI 登录令牌](https://huiai.io/token/)，自动同步官方模型通道与高级扩展能力。 |
| **路线 B：自定义 API Key（自主可控）** | 自建中转 / 厂商官方 API / 第三方兼容服务 | 在「设置 → 模型」中添加 DeepSeek、Kimi、硅基流动、OpenAI 等主流厂商的 Base URL、API Key 与 Model 名称。 |
| **路线 C：本地离线 Ollama（纯本地断网）** | 拥有本地算力显卡，注重 100% 离线隐私 | 一键直连本机运行的 Ollama 服务，纯本地硬件推理计算，完全不消耗外部网络。 |

填写后点击 **检查连接 (Test Connection)**，确认连通成功。

### 步骤 3：开启你的第一个本地任务
1. 在左侧面板选择或创建一个项目文件夹（推荐先选用一个日常测试文件夹）。
2. 选择要调用的助手或 AI 引擎（如 **桌面自动化** 或 **Aion CLI**）。
3. 在输入框中输入一段指令并发送（亦可按 <kbd>Ctrl+M</kbd> 动嘴输入）：

```text
请只读查看当前文件夹，用三句话概括里面包含哪些文件和主要内容。不要修改任何文件。
```

4. 当系统弹出授权提示时，确认路径无误并点击允许。
5. 看到 AI 准确列出本地目录信息，即代表你的本地 AI 工作台已成功就绪！

> 💡 **新手黄金动线建议**：初次上手在「设置」中配好模型后，强烈建议尝试按 <kbd>Ctrl+M</kbd> 体验语音打字，并按 <kbd>Alt+Q</kbd> 呼出置顶小窗。熟悉之后，即可进一步解锁屏幕墙远程桌面、自动化助手与多智能体群聊。

## 🔑 核心概念速记

| 概念 | 作用说明 |
| :--- | :--- |
| **项目 (Project)** | AI 当前拥有操作权限的本地真实文件夹工作空间。 |
| **会话 (Session)** | 围绕特定目标展开的独立对话上下文，可随时归档、恢复与导出。 |
| **屏幕墙与远程控制 (Screen Wall)** | 实时捕获桌面画面的可视化监工视窗，并提供手机触控飞鼠手柄与滚轮接管桌面。 |
| **AI 核心 (AI Core)** | 底层驱动 Agent 的大语言模型内核（如 Claude Code, Codex, OpenCode, Gemini CLI, Ollama 等）。 |
| **团队 (Team)** | 由多个不同专业角色的 Agent 组成的智能体群组，支持分工协作与多轮自主交质。 |
| **本地账号 (Local Auth)** | 存储在本地用于安全加密验证的访问凭证，保障手机端与远程访问安全。 |

## 🛡 本地优先与安全保障

AIPC UP 具备操控真实系统与执行命令的能力，在安全架构上严格遵循**本地优先与最小权限原则**：

* 🏠 **数据本地优先**：你的项目代码、本地文档与运行环境均完整保留在本机，绝不上传私有源码。
* 🔐 **细粒度权限控制**：文件修改、终端命令执行、外部网络访问与键鼠控制默认需要明确授权。
* 👁 **全流程透明可见**：所有工具调用（Tool Calls）、文件变更差异（Diff）与操作日志均清晰展示。
* ⏯ **实时可控与干预**：随时可暂停、中断或回滚 AI 执行中的任务。电脑端按下 <kbd>Shift</kbd> + <kbd>Esc</kbd> 或手机端点击退出即可瞬间断开远程控制。

*了解更多：[安全与隐私说明](https://huiai.io/aipc-up/docs/security/privacy/) · [令牌与凭证安全](https://huiai.io/aipc-up/docs/security/tokens/)*
