## ✨ 什么是 AIPC UP？

**AIPC UP** 并非单一的模型对话框，而是深度整合至 Windows 的**本地 AI Agent 智能工作台**。

它让 AI 真正“入驻”你的电脑——不仅能听懂自然语言与语音指令，更能像资深助理一样，在授权范围内直接调度电脑应用、组织智能体团队协同，安全且自主地交付复杂工作。所有工程文件与运行环境**默认 100% 留存在本地**。

## ⚡ 3 步极速上手

### 1. 下载并启动
前往 [GitHub Releases](https://github.com/learncodesmart/AIPC-UP/releases/latest) 下载最新的 Windows 安装包 `AIPC.UP.Setup.<version>.exe`，运行后秒级启动并创建本地安全账号。

### 2. 配置模型（三种路线任选）
进入 **设置 (Settings)**，按需选择最贴合的接入方案：

| 接入路线 | 适用场景 | 配置方式 |
| :--- | :--- | :--- |
| **路线 A：慧AI 官方接入（推荐）** | 开箱即用，省心首选 | 在「设置 → 慧AI配置」填入 [慧AI 登录令牌](https://huiai.io/token/)，一键同步官方通道与高级功能 |
| **路线 B：自定义 API Key** | 自有中转或厂商直连 | 在「设置 → 模型」配置 DeepSeek、Kimi、硅基流动、OpenAI 等 Base URL 与 Key |
| **路线 C：本地离线 Ollama** | 本地独显算力，100% 离线隐私 | 一键直连本机运行的 Ollama 服务，纯本地硬件推理，断网可用 |

### 3. 开启首个本地任务
在左侧面板选择测试文件夹，选用助手（如 **桌面自动化** 或 **Aion CLI**）并下发指令：

```text
请只读查看当前文件夹，用三句话概括里面包含哪些文件和主要内容。不要修改任何文件。
```

> 💡 **新手推荐动线**：完成配置后，推荐立即按 <kbd>Ctrl+M</kbd> 体验语音打字，按 <kbd>Alt+Q</kbd> 呼出置顶小窗；随后可进一步体验手机扫码远控与多智能体群聊。

## 🛡 本地优先与安全保障

* 🏠 **数据本地自主**：源代码、本地文档与配置均保留在本机，绝不静默上传私有资产。
* 🔐 **细粒度授权**：文件改写、终端执行、网络访问与键鼠控制默认需经确认。
* 👁 **全流程透明**：工具调用明细、代码 Diff 差异与运行日志清晰可视。
* ⏯ **实时中断干预**：随时可暂停任务；远控状态下按 <kbd>Shift</kbd> + <kbd>Esc</kbd> 即可瞬间退出。
